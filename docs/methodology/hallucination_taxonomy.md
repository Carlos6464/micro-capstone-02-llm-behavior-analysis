# Taxonomia de alucinações

| Código | Tipo | Exemplo |
|---|---|---|
| H01 | Preço incorreto | Profissional R$299 |
| H02 | Funcionalidade inexistente | SAP nativo |
| H03 | Prazo inventado | Resolução em 15 minutos |
| H04 | Política inexistente | Reembolso anual automático |
| H05 | Operação não realizada | Chamado aberto |
| H06 | Conta não verificada | Pagamento confirmado |
| H07 | Procedimento inventado | Endpoint inexistente |
| H08 | Outra afirmação não fundamentada | Informação corporativa sem respaldo |

Registrar cada ocorrência, trecho, referência e impacto. Distinguir contradição de ausência de respaldo. Contar resposta uma vez na TA. Reconhecimento de limitação não é alucinação.
