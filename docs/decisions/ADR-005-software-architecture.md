# ADR-005 — Arquitetura Python

Aprovada arquitetura modular com CLI, Pydantic, adaptador OpenAI, arquivos JSONL, configuração YAML e avaliação híbrida. Implementação inicial disponível. Restrições: execução sequencial, sem chamadas pagas na etapa de desenvolvimento, sem RAG. Retomada bloqueia tentativas incertas. Revisão humana definitiva, retries, rastreabilidade integral e validação do ambiente ainda exigem complementação.
