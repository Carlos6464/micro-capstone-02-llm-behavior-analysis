# Procedimentos operacionais

## POP-001 — Recuperação de senha

1. Acessar a página de autenticação.
2. Selecionar Esqueci minha senha.
3. Informar o e-mail cadastrado.
4. Verificar caixa de entrada e spam.
5. Utilizar o link recebido, válido por 30 minutos.

Sem acesso ao e-mail cadastrado, encaminhar ao suporte autenticado.

## POP-002 — Cadastro de usuários

1. Acessar Configurações.
2. Selecionar Usuários e permissões.
3. Selecionar Adicionar usuário.
4. Informar e-mail e perfil de acesso.
5. Enviar convite.

Exclusivo para administradores autorizados, sujeito ao limite contratado.

## POP-003 — Exportação de dados

1. Acessar o módulo desejado.
2. Selecionar Relatórios.
3. Aplicar filtros.
4. Selecionar Exportar CSV.

Depende das permissões.

## POP-004 — Problemas de acesso

1. Verificar conexão com a internet.
2. Conferir endereço oficial da plataforma.
3. Atualizar a página.
4. Testar outro navegador atualizado.
5. Registrar mensagem de erro sem informações sensíveis.

Se persistir, orientar suporte.

## POP-005 — Integrações via API

1. Verificar disponibilidade de API REST no plano.
2. Acessar Configurações e Integrações com perfil autorizado.
3. Consultar documentação técnica da API.
4. Configurar credenciais em ambiente seguro.

Não inventar endpoints, tokens ou integrações.

## POP-006 — Consulta de faturas

1. Acessar plataforma com perfil autorizado.
2. Selecionar Configurações.
3. Acessar Assinatura e faturamento.
4. Consultar histórico de faturas.

Encaminhar divergências ao financeiro.
