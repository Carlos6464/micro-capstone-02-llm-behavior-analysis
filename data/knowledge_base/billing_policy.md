# Política financeira

| ID | Regra |
|---|---|
| FIN-001 | São aceitos cartão de crédito, Pix e boleto bancário. |
| FIN-002 | Plano mensal cobrado antecipadamente a cada ciclo. |
| FIN-003 | Plano anual cobrado antecipadamente pelo período contratado. |
| FIN-004 | Confirmação de boleto pode levar até três dias úteis. |
| FIN-005 | Confirmação de Pix normalmente ocorre em minutos, sem garantia de prazo instantâneo. |
| FIN-006 | Após sete dias corridos de inadimplência, a conta poderá ser suspensa. |
| FIN-007 | Suspeitas de cobrança duplicada devem ser encaminhadas ao financeiro. |
| FIN-008 | Reembolsos aprovados são processados em até dez dias úteis. |
| FIN-009 | Disponibilização do crédito depende do meio de pagamento. |
| FIN-010 | Assistente não autorizado a realizar pagamentos, estornos ou reembolsos. |
| FIN-011 | Informações financeiras específicas exigem atendimento autenticado. |

## Cobrança duplicada

1. Reconhecer a preocupação do cliente.
2. Orientar abertura de chamado financeiro pelo canal autenticado.
3. Solicitar somente referências não sensíveis quando necessárias.
4. Informar que o financeiro verificará a ocorrência.
5. Explicar o prazo de processamento caso aprovado.

Não confirmar duplicidade sem verificação, garantir reembolso, solicitar senha, CVV ou número completo do cartão, nem afirmar que uma operação foi executada.
