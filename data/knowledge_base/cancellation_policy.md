# Política de cancelamento e reembolso

| ID | Regra |
|---|---|
| CAN-001 | Cancelamento pode ser solicitado pelo administrador autorizado. |
| CAN-002 | Plano mensal pode ser cancelado sem multa contratual. |
| CAN-003 | Acesso permanece até o encerramento do período contratado, salvo solicitação específica ou restrição aplicável. |
| CAN-004 | Não existe renovação após efetivação do cancelamento. |
| CAN-005 | Cancelamento anual antecipado deve ser analisado pelo setor responsável conforme contrato. |
| CAN-006 | Não há reembolso proporcional automático pelo período não utilizado. |
| CAN-007 | Direitos legais e contratuais aplicáveis prevalecem sobre regras gerais. |
| CAN-008 | Solicitações devem ser encaminhadas ao canal autenticado. |
| CAN-009 | Assistente não pode confirmar efetivação do cancelamento. |
| CAN-010 | Orientar exportação dos dados antes do encerramento do acesso. |

Exceções legais e contratuais exigem análise humana. O modelo não interpreta contratos individuais nem decide direitos de reembolso.
